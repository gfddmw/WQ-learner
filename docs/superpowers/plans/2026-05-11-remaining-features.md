# WQ Learner 后续功能实施计划

> **给自动化开发者的要求：** 实施本计划时，按功能逐项执行。每个功能都要独立验证；功能完成后先向用户汇报，得到用户确认后再提交并推送到 GitHub。

**当前方向：** 从本地开发版升级为 Serverless 云端版。后端业务逻辑由阿里云函数计算承载，图片存储使用阿里云 OSS，结构化数据使用云端数据库。Android App 打开后应直接访问公网 API，不再依赖用户手动启动本机 FastAPI。

**核心目标：**
- 后端业务逻辑运行在阿里云函数计算，不需要手动启动本机后端。
- Android App 使用函数计算 HTTP 触发器地址或自定义域名访问云端 API。
- 图片上传和访问走 OSS，不依赖函数计算本地磁盘。
- 用户、错题、练习记录存入云端数据库，不依赖本地 SQLite 作为正式数据源。
- 每个功能完成后都能单独验证、单独提交。

**技术栈：** Python、FastAPI、pytest、Android Kotlin、Jetpack Compose、JUnit、Gradle、阿里云函数计算、阿里云 OSS、云端数据库（优先选择简单可用方案，后续可升级 RDS MySQL/PostgreSQL 或表格存储）、HTTPS 自定义域名、OCR/视觉模型和大模型服务。
